# Apify Job Aggregator

A multi-source Apify Actor that scrapes job listings from Google Jobs and Indeed, normalizes results, and deduplicates output.

## Features

- Multi-source aggregation (Google Jobs + Indeed)
- CAPTCHA detection for Google Jobs
- Skill extraction, normalization, and deduplication
- Simple unit-style tests

## Usage

```bash
npm install
npm start
```

## Testing

```bash
npm test
```

## Input

See `INPUT_SCHEMA.json` for input parameters.
